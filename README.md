# Strategic Game Platform

A modular, multi-game strategic bot management platform.

## Project Goals

- Support multiple authorized game integrations.
- Manage multiple bot instances.
- Execute configurable strategies.
- Monitor bot health and performance.
- Provide centralized bot lifecycle management.
- Support commercial SaaS and custom deployments.

## Development Environment

- Windows
- Visual Studio Code
- Python
- TypeScript / Next.js
- Docker Desktop
- PostgreSQL
- Redis
- RabbitMQ
